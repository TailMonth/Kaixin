# 开心桌宠 · 水彩 UI 实施提示

## 任务背景

基于现有开心桌宠 WPF 应用，重新设计设置窗口、桌宠右键菜单和番茄钟悬浮计时。功能与业务约束以 `docs/开心桌宠-设计文档.md` 和当前代码为准，视觉与组件以 `documents/designs/kaixin-watercolor_design_system.md` 为准，交互外观参考 `documents/ux-design/kaixin-watercolor-prototype.html`。

本次用户明确要求“水彩、低饱和、温馨、猫咪同款配色”，覆盖旧 PRD 中“纸纹不进入设置窗口、保持 Fluent 风格”的限制。不得改成 React 或另起 Web 应用；HTML 仅作设计原型。

## 必须保留

- 设置五页与所有现有设置项、范围、默认值、即时保存和错误提示。
- 时长在新阶段生效，当前计时不被打断。
- 桌宠右键菜单的单层命令、状态行、启用/禁用与勾选状态。
- 托盘菜单和命令分发不被破坏。
- 计时收起态只读、点击穿透，展开态四个操作及悬停协调。
- 现有数据模型、音频服务、状态机、设置存储和全局快捷键逻辑。
- 键盘、焦点、DPI、多显示器、减少动效与性能要求。

## 视觉实施

1. 新建统一主题 ResourceDictionary，实现纸色、猫黑、暖灰、鼠尾草绿、耳粉和功能色 tokens。
2. 设置窗口采用暖纸背景、淡纸纹、细线卡片和浅绿选中导航；卡片标题与内容左对齐。
3. 水彩质感使用静态、可缓存、九宫格素材；不得用大尺寸模糊、逐帧纹理或透明文字实现。
4. 图标统一为 1.5 DIP 圆头线性风格，可从现有 Path 图标演进，不引入表情符号。
5. 右键菜单改为独立 WPF 非模态浮层，复用命令，不尝试给 Win32 原生菜单刷颜色。
6. 番茄钟浮层沿用现有窗口契约，只替换视觉模板并同步尺寸、定位常量。

## 可视化交互实施

### 番茄钟

- 专注、短休息、长休息改为区间滑杆，范围沿用 1–180、1–60、1–60 分钟。
- 长休息轮次改为 1–12 滑杆，附轮次点预览。
- 顶部增加由当前设置生成的节奏摘要：专注、短休息、长休息及轮次关系；仅作预览。
- 当前值以只读值签显示，包含单位与上下限；不再以数字框作为主要操作。
- 自动流转、显示与提醒继续用二元控件，视觉改为带完整标签的开关。

### 行为

- 玩耍最长时长、待机入睡、专注安静延迟全部使用滑杆。
- 范围沿用 10–300 秒、1–240 分钟、0–60 分钟；0 分钟显示“立即”。
- 关闭自发玩耍时，玩耍时长滑杆显示禁用并保留当前值。

### 音效

- 三个音量滑杆采用同一组件，当前百分比常显；静音后禁用并保留原值。
- 试听、替换、还原按钮统一图标与文字层级；自定义音效显示文件名与还原入口。

### 常规与关于

- 宠物名字仍是文本输入，这是适合文本的场景，不强行可视化。
- 重置位置卡可加入静态屏幕示意，按钮行为不变。
- 关于页可放小尺寸开心头像；重置所有设置保持二次确认与危险状态。

## 工程步骤

1. 先建立主题 tokens 与通用控件模板，不修改业务行为。
2. 改造设置页布局和滑杆绑定，逐步删除仅服务于旧数字框的校验路径；保留边界校验。
3. 实现自绘右键菜单浮层并接入现有命令与状态。
4. 替换计时浮层视觉并验证收起/展开尺寸、点击穿透和屏幕边缘定位。
5. 完善焦点、AutomationProperties、键盘操作、禁用与减少动效。
6. 运行现有测试并手动验收五页、菜单、计时、DPI 和性能。

## 验收标准

- 所有可见设置均能通过鼠标与键盘修改，滑杆值与保存值一致。
- 不存在只有颜色、没有文字或图形辅助的关键状态。
- 纸纹不影响文字清晰度，拖动滑杆与打开菜单无明显掉帧。
- 五页无内容丢失；小窗口可滚动，150% DPI 无裁切。
- 右键菜单不抢焦点，Esc/外部点击关闭，命令与原生菜单一致。
- 计时标签收起时点击穿透，展开后四个按钮均可用。
- 没有改变时长生效时机、计时状态、设置存储格式或音频行为。
