# 开心桌宠 · 水彩设计系统

版本：2026-10-28  
范围：设置窗口（常规、番茄钟、音效、行为、关于）、桌宠右键菜单、番茄钟悬浮计时。  
目标：以开心的暖灰虎斑、鼠尾草绿眼睛、耳粉与奶白毛色建立低饱和水彩界面；操作尽量可视化，同时保留现有功能、范围、时序与键盘可访问性。

## 1. 设计原则

1. **猫是主角，界面是手账**：纸色、淡晕染、细线稿只营造陪伴感，不用插画挤占功能。
2. **先看懂，再微调**：时长、轮次和音量用滑杆、节奏条、轮次点和实时摘要表达；当前值始终可见。
3. **低饱和不等于低对比**：浅色只用于底色，正文始终使用猫黑；状态不能仅靠颜色区分。
4. **静态纸感，轻量动效**：纸纹不动、不模糊文字；动画只反馈状态和操作。
5. **桌面 UI 保持轻**：收起态计时仍小巧、只读、点击穿透；右键菜单仍是一层命令。

- 主按钮为 `eye.deep` 底 + `#FFFCF5` 字；浅绿选中态仍使用猫黑文字。
- 专注和休息同时通过圆点、文字或沙漏颜色表达；危险操作同时提供明确文字。

## 3. 字体与排版

- 中文：`Microsoft YaHei UI`；英文与数字：`Segoe UI Variable`。
- 倒计时使用 Tabular Figures，避免每秒宽度跳动。
- 页面标题：24/32 DIP，Semibold。
- 卡片标题：16/24 DIP，Semibold。
- 正文与控件：14/22 DIP，Regular。
- 辅助文字：12/18 DIP，Regular。
- 当前滑杆值：14/20 DIP，Semibold；展开倒计时：34/40 DIP，Semibold。
- 手写字体只允许用于装饰性签名，不用于菜单、正文或数值。

## 4. 网格、尺寸与形状

- 4 DIP 基网：`4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48`。
- 设置窗口建议 840×620 DIP，最小 680×500；左侧导航 176 DIP，右侧内容区滚动。
- 内容页边距 28；卡片内边距 20–24；卡片间距 16；表单行间距 16。
- 常规控件高度 36；按钮与图标命中区域至少 36×36。
- 小控件圆角 8；卡片、菜单、计时浮层 14；窗口 12。
- 卡片边框 1 DIP `fur.outline`，透明度约 65%；浮层阴影 `0 6 20`、黑色 10%。
- 不使用厚重投影、玻璃拟态或大面积实时模糊。

## 5. 水彩材质

- 窗口、卡片、菜单和计时浮层使用静态细纸纹，视觉不透明度 2%–4%。
- 晕染只出现在窗口背景、选中导航、主操作和阶段标记；单块颜色透明度约 8%–16%。
- 卡片外框可有轻微手绘感：偏移不超过 0.75 DIP，不能影响文本和控件对齐。
- 滑杆轨道、输入框、小图标和焦点环保持规整，避免“所有东西都毛边”。
- 纸纹与边框素材使用可缓存九宫格 PNG；不得把纸纹烘焙进文字。

## 6. 核心组件

### 6.1 水彩滑杆

- 轨道高 5 DIP，滑钮 18 DIP；已选区间使用 `eye.sage`，未选区间使用 `fur.warmGray`。
- 标签在左，当前值签在右；轨道下方显示最小值与最大值。
- 当前值签只读，不是数字输入框；格式包含单位，例如 `25 分钟`、`90 秒`。
- 支持拖动、点击轨道、方向键与 PageUp/PageDown；步进与现有业务规则一致。
- 悬停放大滑钮至 20 DIP，焦点使用 2 DIP 深绿外环；拖动时只在 160ms 内更新视觉，不写高频动画。

### 6.2 轮次点与节奏条

- 长休息轮次使用滑杆 + 一排小圆点/爪印，当前轮次数同时以文字显示。
- 番茄钟顶部显示“专注 → 短休息 → … → 长休息”的静态节奏摘要，由当前设置实时生成。
- 节奏条是设置预览，不是正在运行的计时器，不引入新的运行控制。

### 6.3 开关

- 尺寸 42×24 DIP；开启为深绿，关闭为暖灰；圆形滑钮为纸白。
- 二元设置统一使用开关，标签仍完整可读；静音等状态附文字或图标。
- 不用只有图标、没有标签的开关表达复杂设置。

### 6.4 按钮

- 主按钮：深绿底、纸白字，用于当前卡片内最重要的主动操作。
- 次按钮：纸白底、暖灰边；危险按钮使用危险色描边和文字。
- 悬停仅加深底色或出现浅绿晕染；按下下移 1 DIP；禁用不透明度 45%。
- 图标按钮必须提供 ToolTip 与 AutomationProperties.Name。

### 6.5 导航与卡片

- 五页顺序不变；选中项使用浅绿水彩底 + 3 DIP 深绿侧条 + 对应线性图标。
- 卡片用分组标题和说明建立层级，不在每张卡片添加无功能插画。
- 说明文字放在相关控件附近；设置即时生效或下阶段生效的提示保持可见。

### 6.6 右键菜单

- 最小宽度 248 DIP，菜单项高 36；纸色底、细暖灰边、轻阴影。
- 顶部状态区使用猫眼小图标 + `开心 · 空闲` 或计时状态，保持禁用、不可点击。
- 当前计时命令放在浅绿分组底上；其余按玩耍、显示、应用、退出分组。
- 勾选状态用深绿对勾；危险退出使用猫黑即可，不渲染成红色警报。
- 保持单层菜单，点击外部或 Esc 关闭，不抢当前应用焦点。

### 6.7 番茄钟浮层

- 收起态约 84×30 DIP：暖纸底、阶段圆点、等宽时间；只读、点击穿透。
- 展开态约 216×136 DIP：大时间、细进度水彩色带、结束/暂停/跳过/设置四个按钮。
- 展开态仍沿用 350ms 悬停出现、移出 1.5 秒收回；不变成常驻大面板。
- 专注使用暖金沙色，休息使用鼠尾草绿，暂停使用暖灰并显示暂停符号。

## 7. 动效

| 场景 | 时长 | 缓动 |
| --- | --- | --- |
| 悬停 | 120ms | ease-out |
| 按下 | 80ms | ease-out |
| 开关、选中、滑杆值签 | 160ms | `cubic-bezier(.22,1,.36,1)` |
| 浮层进入 | 200ms | `cubic-bezier(.22,1,.36,1)` |
| 浮层退出 | 150ms | `cubic-bezier(.4,0,1,1)` |

- 纸纹不逐帧变化，避免“沸腾”。
- 减少动效时，仅保留不超过 80ms 的透明度反馈。
- 不因拖动滑杆触发布局跳动或整页重新渲染。

## 8. 状态与可访问性

- 焦点：2 DIP 深绿外环，外留 2 DIP 纸色间隔。
- 正文与背景对比度至少 4.5:1；关键图形与大字至少 3:1。
- 错误：危险色描边 + 错误文字；不能仅靠红色。
- 禁用：45% 不透明度、不可点击，并保留原因提示。
- 所有滑杆、开关和图标按钮支持键盘与屏幕阅读器名称。
- 1080p、150% DPI 下验证边框、命中区域、文本换行和浮层定位。

## 9. WPF 落地约束

- 颜色、字号、间距和 ControlTemplate 统一放入 ResourceDictionary，避免继续散落硬编码。
- 使用 DIP、UseLayoutRounding、SnapToDevicePixels；画刷和可复用资源冻结。
- 水彩纸纹和手绘边框采用静态九宫格 PNG，纯色纸底兜底，不依赖 Acrylic。
- 滑杆保留现有 Minimum、Maximum、ValueChanged、AutomationProperties 和保存节流契约。
- 设置修改仍按现有逻辑即时或下一阶段生效，不改变计时状态机。
- 原生 Win32 菜单无法通过 WPF Style 换肤；需要独立 WPF 非模态菜单窗口并复用现有命令。
- 计时浮层保留收起态 `WS_EX_TRANSPARENT`、展开态接收点击及现有定位逻辑。
