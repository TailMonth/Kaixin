## 0. 使用方式

1. **不要先画 200 张。** 先完成第 2 节的角色标准稿，再完成第 3 节的垂直切片，接入软件验证大小、锚点、帧率和观感。
2. 第 3 节通过后，再按第 4 节补全所有动作。
3. 每个任务都按「起稿 → 线稿 → 上色 → 导出 → 对齐 → 预览 → 验收」勾选，不要跳步。
4. 画布、锚点、命名、帧率一旦确定，不要中途改；否则所有帧都要返工。
5. 这里的“手绘”包括：
   - 数字手绘（Procreate / Photoshop / Krita 等）；
   - 纸绘线稿 + 数字上色；
   - 纯传统水彩 + 扫描。
   三种都可以，但推荐前两种，原因见第 1.1 节。

## 1. 开工前必须定下的五件事

### 1.1 选择绘制媒介

| 方式 | 优点 | 缺点 | 建议 |
| --- | --- | --- | --- |
| 数字手绘水彩 | 图层、撤销、颜色一致、透明背景容易、可复用纸纹 | 需要数位板/ iPad，笔触要练 | **最推荐**，适合 150+ 帧的动画 |
| 纸绘线稿 + 数字上色 | 保留真实铅笔/墨线手感，上色和抠图容易 | 扫描、对齐、线稿清洁需要流程 | **推荐**，兼顾手绘质感和动画可控性 |
| 纯传统水彩 + 扫描 | 最真实的水彩纸感 | 150+ 帧的颜色、纸纹、纸白边、扫描一致性很难 | 只建议用于角色定稿/表情/关键帧，不建议全动画 |

**纸绘必须注意：** 白四肢 + 白纸背景会导致抠图时白色毛和纸底混在一起。建议用**微灰/鼠尾草色纸**或给白毛加一点暖灰阴影，并用不透明白颜料/白水粉提亮；或者只画线稿，上色在数字端完成。

### 1.2 锁定角色身份

最终角色设定（必须逐帧一致）：

- 灰棕虎斑，额头清楚的 M 纹，身上不规则深灰条纹。
- **没有白围兜、没有白胸口、没有白脖子**；脖颈和胸口是虎斑。
- **四肢与爪子是自然白色毛**，不是袜子、手套、鞋或衣物；白色与虎斑的交界要柔和自然。
- 小范围白色口鼻/下巴，白色止于下巴，**不能延伸成白围兜或白脖子**。
- 绿眼、粉鼻、深色尾尖、尾巴蓬松。
- 不戴项圈、铃铛、蝴蝶结、真实手套、袜子、鞋、帽子或任何配饰。
- 不出现其他动物、花卉边框、文字、数字、Logo。

把这段写成一张**身份锁定卡**贴在画板前。每次开新动作先对照，不要凭记忆画。

### 1.3 颜色与笔触

| 用途 | 色值/说明 |
| --- | --- |
| 虎斑基色 | `#7B7469` |
| 虎斑阴影 | `#5B564E` |
| 条纹 | `#4A473F` |
| 白四肢/白口鼻 | `#F8F4EA`，不要用纯纸白 `#FFFFFF` 直接留白 |
| 耳内 | `#D9A6A0` |
| 鼻头 | `#E9A0A6` |
| 虹膜 | `#9DBE86` |
| 瞳孔 | `#2E342A` |
| 线稿 | 暖深褐 `#4A443C`，约 55% 不透明度 |
| 毛线球 | `#C9604F` + `#E0A24C` |
| 沙漏木框 | `#B89A74` |
| 沙漏沙色 | 专注暖金 `#D9B36C`；休息鼠尾草绿 `#9BB68C`（可由软件染色，但建议准备两套参考） |

**水彩风格：** 细铅笔/墨线勾形，透明薄涂，颜色低饱和，纸纹只在角色内部；不要粗黑描边、数字气笔感、3D 高光。

**每帧保持一致：** 同一动作的所有帧一次性调好一碟颜料/一套笔刷；不要今天画 3 帧、明天再调一个新颜色。

### 1.4 画布与锚点

| 项目 | 规格 |
| --- | --- |
| 单帧画布 | **384×384 px**（2x 母版，含动作余量） |
| 猫的高度 | 约 300 px（对应 150 DIP） |
| 地面线 | 画布底部上方 24 px，即 y=360 |
| 水平中心 | x=192 |
| 默认猫的脚底 | 落在 y=360 的地面线 |
| 安全边 | 距画布边缘至少 24 px，尾巴/耳朵/爪尖不要贴边 |
| 导出 | 裁切到内容包围盒 + 8 px 安全边；保持原始锚点偏移 |
| 道具画布 | 沙漏 128×192 px；毛线球 64×64 px；单独导出 |
| 纸纹 | 固定一张，叠在所有帧上或只在角色内部；不能每帧随机变化 |

**为什么是 384×384：** 150 DIP 的猫在 2x 下已经 300 px 高；再给扑击、甩尾、拖拽留出余量。最终软件会按帧矩形裁切，不需要每帧都塞满画布。

### 1.5 帧率与交付格式

| 动作 | 目标帧率 | 循环 |
| --- | --- | --- |
| 待机呼吸 | 10–12fps | 是 |
| 眨眼/耳朵/尾巴叠加 | 12–18fps | 否/是 |
| 睡觉呼吸 | 6–8fps | 是 |
| 玩耍 | 15–24fps | 分段 |
| 拖拽/下落 | 15–24fps | 否 |
| 沙漏放置/翻转 | 12fps | 否 |
| 界面特效（爱心/Zzz） | 10–12fps | 否/是 |

交付格式：

- 源文件：PSD / TIFF / Procreate 原生文件，保留图层。
- 导出：PNG-24、透明背景、sRGB；不要带矩形纸底。
- 预览：每个动作一个 GIF/MP4，按目标 fps 播放，标明缩放比例。
- 元数据：每个 clip 的帧数、fps、循环、帧事件、锚点偏移。
- 命名：见第 7.2 节。

## 2. 阶段 0：角色标准稿与制作模板（P0）

**目标：先锁定“这只猫是谁”，再开始任何动画。预计 2–4 天。**

### 2.1 画前测试

- [ ] 打印/建立 384×384 模板：地面线 y=360、中心线 x=192、头部圆圈、眼睛水平线、安全边。
- [ ] 做 3 组颜色测试：虎斑基色、白四肢、白口鼻；在最终使用的纸/屏幕上看效果。
- [ ] 做 5 个笔刷/笔触测试：线稿、毛发边缘、水彩晕染、阴影、白色提亮。
- [ ] 确定纸纹方案：数字纸纹贴图，或纸绘扫描后的统一纸纹层。
- [ ] 把参考照片里的白围兜白胸口标记为“不使用”，白四肢标记为“保留”。

### 2.2 坐姿三视图

- [ ] A1 正面坐姿：四爪、尾巴、耳朵完整入画。
- [ ] A1 左侧坐姿：看清胸口虎斑、白色前腿起点、后腿折叠。
- [ ] A1 背面坐姿：背部和尾巴花纹合理，没有凭空多出的白围兜。
- [ ] 三张图同一高度、同一地面线、同一比例。
- [ ] 头部特写：眼睛形状、鼻子、嘴巴、白色口鼻范围。
- [ ] 不画项圈/配饰；检查没有白色胸口、白脖子。

**通过标准：** 三视图能看出是同一只猫；白色只出现在四肢、爪子、口鼻/下巴；胸口是虎斑。

### 2.3 头部与表情基准

- [ ] 头部正面/3/4/侧面结构草图。
- [ ] 眼睛：睁开、半闭、闭合、眯眼四种基准。
- [ ] 嘴巴：闭合、小张嘴、喵叫张嘴三种基准。
- [ ] 耳朵：前倾、放松、后压三种基准。
- [ ] 九种表情草图（详见 3.2 与第 5.7 节）。
- [ ] 确定眼线、鼻尖、嘴缝、耳朵根部的固定坐标，方便做表情叠加。

### 2.4 道具基准

- [ ] 沙漏正/侧视图；木框、玻璃、沙、落沙分层；**没有数字/刻度/文字**。
- [ ] 沙漏专注暖金、休息鼠尾草绿两套沙色小样。
- [ ] 毛线球一个完成稿 + 8 个旋转角度草图。
- [ ] 猫与沙漏、猫与毛线球的比例草图（沙漏约 55×80 DIP，球约 22 DIP）。
- [ ] 接触阴影：待机、睡觉、趴卧三种软阴影形状。

### 2.5 身份锁定板

- [ ] 一张 A4/画布大小的“角色身份证”：三视图 + 头部 + 色卡 + 不可添加元素清单。
- [ ] 签字确认：从这张图开始，所有动画必须和它一致。

**常见错误（画完先检查）：**

- 习惯性给猫加白围兜/白胸口，因为原照片有。
- 白色四肢画成了袜子/手套，边缘太硬或出现裁剪线。
- 白色口鼻延伸成白脖子。
- 给猫加项圈、铃铛、蝴蝶结。
- 尾巴尖颜色忘了加深。
- 眼睛画成黄色/蓝色。
- 把参考图里的花卉、其他动物带进画面。

### 3.2 切片任务清单

- [ ] 完成 A1 + 头部基准（第 2 节）。
- [ ] 画 `idle.breath` 12 张：先画 3 个关键姿势（吸气/呼气/中间），再补 9 张过渡。
- [ ] 画 `idle.blink` 3 张：睁眼、半闭、闭合；眼睛位置与待机头一致。
- [ ] 画 `sleep.curl` 8 张：从坐姿到蜷起的连续过程。
- [ ] 画 `sleep.breath` 6 张：只让侧腹起伏，身体轮廓尽量不动。
- [ ] 画 `timer.place_hourglass` 8 张：猫的爪子伸向固定锚点，**沙漏留空**；沙漏单独画。
- [ ] 画沙漏分层：木框+玻璃、上层沙、下层沙、落沙；准备专注/休息两种沙色参考。
- [ ] 画 `play.pounce` 8 张、`play.bat` 8 张；球留空，后期合成。
- [ ] 画毛线球 8 个旋转角度，单独导出。
- [ ] 画 4 个表情和对应的眼/嘴叠加层。
- [ ] 画待机/睡觉接触阴影。
- [ ] 导出 PNG 序列，按目标 fps 做 GIF/MP4 预览。
- [ ] 接入软件测试：100%/150%/200% 缩放、浅/深壁纸、沙漏/时间标签构图。
- [ ] 跟软件确认：帧数、帧率、锚点、内存、图层顺序没有返工风险。

**切片验收标准：**

- 猫坐着时脚底不滑动，呼吸不漂移。
- 眨眼与呼吸可以叠加，没有头部跳变。
- 睡觉循环看不出“首尾接缝”。
- 沙漏摆放位置与软件锚点一致；沙漏不是画在猫帧里。
- 毛线球在猫身边的比例自然，不穿模。
- 透明边缘在深色/浅色壁纸上都干净；白四肢没有吃掉边缘。

### 4.2 全量任务勾选

**待机与睡觉**

- [ ] `idle.look_around`：3 个关键头位 + 过渡；眼睛跟随。

- [ ] `idle.stretch`：前爪伸出、胸压低、尾巴上翘、回坐。

- [ ] `idle.tail_sway`：8–12 帧尾尖摆动。
- [ ] `sleep.twitch`：闭眼状态下的耳朵/胡须抽动。

## 5. 逐动作绘制笔记

### 5.1 `idle.breath` 坐姿呼吸

- 帧数：12 张；fps 10；循环。
- 关键姿势：
  1. 中性坐姿；
  2. 吸气：胸腔抬起 1–2px，头部略高；
  3. 呼气：胸腔回落的中间帧。
- 只有胸、肩、头轻微变化；脚底、尾巴根、耳朵位置不动。
- 首尾不要复制同一张；如果循环播放 12 张，最后一帧回到第 1 帧时应该自然衔接。
- 水彩上色时一次调够颜料，避免 12 帧颜色漂移。
- 通过：循环播放 3 次看不出接缝，脚不滑。

### 5.2 `idle.blink`

- 3 张：睁开 → 半闭 → 闭合；或 4 张加一张半睁。
- 眼睛位置必须与待机头部完全对齐。
- 只画眼睛区域，不重画整只猫；边缘做 1–2px 羽化。
- 与呼吸叠加时不能出现头部抖动。

### 5.3 `idle.tail_sway` / `idle.ear_twitch`

- 尾巴 8–12 帧，尾尖摆动 3–5px；根部和身体不跟着动。
- 耳朵 4–5 帧，单耳向外/向后，另一只耳不动。
- 作为叠加层导出，背景透明。

### 5.4 `idle.look_around` / `idle.groom` / `idle.stretch`

- look：头转向左/右，眼睛先动或头眼同步；身体保持坐姿。
- groom：抬前爪 → 舔两下 → 擦同侧脸 → 回正；注意白前腿与虎斑胸口的交界。
- stretch：前爪向前伸、胸压低、尾巴上翘，再回坐姿；可复用醒后动作。
- 这些动作是“可被打断”的；结束帧要能自然回到 `idle.breath` 的第 1 帧。

### 5.5 `sleep.curl` / `sleep.breath` / `sleep.wake`

- curl 8 帧：坐 → 低头 → 前身趴下 → 尾巴绕过来 → 闭眼。
- breath 6 帧：只让侧腹起伏，身体轮廓和头部几乎不动。
- wake 6 帧：睁眼 → 抬头 → 前爪撑起 → 回坐姿。
- Zzz 单独叠加，不画在猫身上。
- 睡姿的接触点更宽，阴影要换成睡眠阴影。
- 循环检查：6 帧呼吸循环不应出现身体位移。

### 5.6 `play.notice` / `pounce` / `bat` / `chase` / `flop`

- 猫和毛线球分开画；每帧留出球的锚点位置，不要烘焙球。
- 扑击/追球时猫在 384 画布内移动，脚底不总是同一个点；确保尾巴、耳朵、爪子不出安全边。
- 拍球循环 8 帧：前爪交替，第 4 帧接触球；在 JSON 里标记音效和物理脉冲。
- 追球是横向位移；不要画成原地踏步。
- 玩累趴下 6 帧，身体压低，尾巴放松。
- 通过：连续播放时爪子与球的距离合理，不穿模，尾巴不消失。

### 5.7 9 个表情

| 表情 | 眼睛 | 耳朵 | 嘴 | 用途 |
| --- | --- | --- | --- | --- |
| 平静 | 正常睁开 | 放松 | 闭 | 默认 |
| 眨眼 | 半闭/闭 | 不动 | 闭 | 叠加 |
| 开心 | 弯月闭眼 | 放松 | 小微笑/闭 | 摸猫、完成 |
| 困倦 | 半睁 | 略后 | 闭 | 睡前 |
| 好奇 | 放大 | 前倾 | 闭/小张 | 开始专注、看球 |
| 不满 | 眯眼 | 后压 | 平线 | 连续拖动 |
| 喵叫 | 正常 | 前倾 | 张圆 | 交互音效 |
| 专注 | 瞳孔略收 | 前倾 | 闭 | 看球/专注陪读 |
| 被摸 | 闭眼弯月 | 放松 | 小微笑 | 单击猫 |

- 九个表情同一头部角度、同一缩放、同一眼线；不要换脸型。
- 白色口鼻范围保持一致，不要越画越大变成白围兜。
- 如果做眼/嘴叠加，导出时保持透明背景和对齐基准。

### 5.8 拖拽与下落

- grab 4–5 帧：被拎起，四肢和尾巴自然下垂；**不要画人手**。
- hold 4 帧：轻微摆动循环。
- fall 4–6 帧：尾巴上翘、身体拉长。
- land 4–5 帧：爪子接触地面、屈膝缓冲、回待机。
- 在软件里窗口跟随鼠标移动；帧里的猫只表现姿态，不需要画背景或阴影变化。
- 如果拖拽时沙漏和时间标签淡出，落地后猫身边再淡入沙漏；帧本身不包含沙漏。

### 5.9 沙漏动作与道具

- 沙漏是独立道具；猫的放/碰/推动作里不要烘焙沙漏。
- 沙漏画布 128×192 px（2x），底部中心为锚点。
- 分层：
  1. 木框 + 玻璃 + 高光；
  2. 上层沙；
  3. 下层沙；
  4. 落沙细线；
  5. 翻面方向（或在软件中翻转）。
- 沙漏上**不能有数字、刻度、时间文字**；时间由界面显示。
- 沙色准备暖金/鼠尾草绿两版；如果软件染色，先确认不会把水彩质感染脏。
- 猫与沙漏合成检查：爪子接触位置、沙漏不遮住猫脸、时间标签在沙漏上方不挡猫。

### 5.10 毛线球

- 8 个旋转角度；球直径约 44 px（2x），线头自然。
- 主色赭红 + 芥末黄；黑色线稿不要太重。
- 画布 64×64 px，透明背景；球心为锚点。
- 由代码做物理弹跳和旋转，不需要逐帧画轨迹。

### 5.11 特效与图标

- 爱心 6 帧：从猫头附近升起，逐渐透明。
- Zzz 6 帧：从睡姿上方飘出，循环；不要画在猫帧上。
- 问号 4 帧：暂停/疑惑时短暂出现。
- 接触阴影：软边、低透明度，单独一层；不要烘焙进猫帧。
- App 图标：1024×1024 母版，水彩猫头；托盘 16/20/24/32/48，无白围兜、无配饰；阶段圆点由 UI 绘制或单独切图。

## 6. 水彩动画制作流程

### 6.1 推荐流程（数字或混合）

1. **定模板**：384×384、地面线、头/眼基准线、安全边。
2. **画关键姿势**：先画动作的 3–5 个关键帧，不急着补中间帧。
3. **做动态预览**：把关键帧按时间排好，用 GIF 看节奏；不对就改关键帧。
4. **补中间帧**：用洋葱皮/透写台，保持脚底、头、尾巴的弧线。
5. **线稿批处理**：同一动作的所有线稿一次画完，保持线宽一致。
6. **水彩上色批处理**：一次性调够颜料，按“底色 → 阴影 → 白色四肢/口鼻 → 眼睛/鼻子 → 细节”的顺序逐帧完成。
7. **导出与裁切**：保留统一画布，导出透明 PNG，再按内容裁剪。
8. **对齐与预览**：按目标 fps 合成 GIF/MP4，检查循环、抖动、颜色漂移。

### 6.2 传统纸绘补充

- 用固定画板/定位钉，所有帧同一张纸的同一位置；或使用带定位孔的动画纸。
- 用 2–3 倍最终尺寸画，扫描 600dpi，最后缩小到 384×384。
- 用微灰/鼠尾草纸或给白四肢加暖灰边缘，避免抠图时和白纸混在一起。
- 扫描时固定光源、白平衡和相机位置；全部帧一次性扫描。
- 颜色一次调够，记录颜料配方；同一动作不要跨天换色。
- 纯水彩的纸纹逐帧不同，建议用数字统一纸纹，或接受非常轻微的纸纹变化。
- 纸绘更适合角色定稿、表情和关键帧；全动画建议转数字上色。

### 6.3 透明边缘与抠图

- 不要用纯白背景做最终抠图；白四肢/白口鼻会和背景混。
- 用鼠尾草绿或中灰的哑光背景，配合手动蒙版/选择主体。
- 水彩边缘保留 1–2px 的柔和过渡，但不要留下绿边/白边。
- 在浅色和深色壁纸上分别检查边缘。
- 不要把矩形纸纹、投影、桌面阴影一起导出。

### 6.4 循环与帧事件

- 如果循环是 12 帧，就画 12 张不同的帧；不要再复制第 1 张作为第 13 张，否则播放会停顿一帧。
- 如果为了节奏复制了尾帧，在元数据里标明 `holdLastFrame`，导出时由工具处理。
- 帧事件直接记录在 JSON 中，例如：
  - `play.bat` 第 4 帧：音效 `interaction.ball_bat` + 球的速度脉冲；
  - `drag.land` 第 3 帧：落地尘/音效；
  - `focus.celebrate` 第 2 帧：爱心粒子；
  - `timer.place_hourglass` 第 6 帧：沙漏出现/音效。

## 11. 不要画的东西

- 白围兜、白胸口、白脖子、白色“领子”。
- 真实的手套、袜子、鞋、衣服、项圈、铃铛、蝴蝶结。
- 沙漏上的数字、刻度、时间文字。
- 猫帧里的沙漏、毛线球、爱心、Zzz、阴影（这些都要分开）。
- 其他动物、花卉边框、背景草地、桌子、文字、Logo、签名。
- 粗黑描边、3D 高光、写实毛发、霓虹色。
- 被裁切的耳朵/尾巴/爪子。
- 循环中重复的首帧（会造成停顿）。
- 每帧都不一样的纸纹（会“沸腾”）。

## 结语

这条美术路线的核心不是“画得多”，而是“先锁定角色、先跑通垂直切片、再批量生产”。白围兜已经去掉、白色四肢保留、猫不戴任何配饰；只要身份卡和锚点不变，后续 150+ 帧才不会反复返工。
